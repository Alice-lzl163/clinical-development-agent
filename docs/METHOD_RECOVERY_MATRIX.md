# Method Recovery Matrix

## Scope and grading

This is a forensic inventory, not a statistical endorsement. The current key set is the 49-key menu in upstream `main` at commit [`e540d441883b`](https://github.com/medstatstar/ct-samplesize/tree/e540d441883b). Local provenance was traced primarily to the last fully local release, v3.8.1 at [`3417563d832b`](https://github.com/medstatstar/ct-samplesize/tree/3417563d832b), with earlier milestones used where they identify the origin of an implementation. No formula below was supplied from memory: algorithm descriptions paraphrase the cited historical source. “Exact” means exact only in the sense claimed by that source or delegated package; it does not mean independently validated.

Recoverability grades:

- **A** — a routed local implementation can be restored directly. Package installation and verification may still be required.
- **B** — executable implementation exists, but extraction or semantic refactoring is required before it can represent the advertised method safely.
- **C** — only a formula or specification was found.
- **D** — no implementation or sufficient specification was found.

`validation required` means this audit found no independent numerical oracle in the repository. Changelog self-tests are recorded as provenance, not treated as external validation.
